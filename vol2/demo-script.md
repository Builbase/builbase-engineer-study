# 実演デモ台本（第2回）

60分の中で2回入れる。
どちらも自分の`~/.claude`をそのまま映す。設定の中身は多いので、見せる範囲を2つに絞る。

## 共通の準備

- [ ] 画面共有時のターミナル文字を18pt以上にする
- [ ] 通知、メール、チャットのプレビューを切る
- [ ] `~/.claude/settings.json`は映さない（hookのコマンド行にローカルパスが並ぶ）。映すのは`CLAUDE.md`と`/context`の出力だけ
- [ ] `/context`の出力にプロジェクト名や顧客名が出ないディレクトリで起動する（`~`直下か、デモ用の空リポジトリ）
- [ ] 実演2で使うダミーの`.env`を用意し、hookが本当に止めることを前日に確かめる
- [ ] ネットワーク障害に備え、各実演のスクリーンショットを用意する

## 実演1: 指示を打つ前に読み込まれているものを見る

挿入位置は7枚目のあと。所要時間は3分。

見せたいことは、何も打っていないのに、すでに数千トークンが読み込まれていること。

### 手順

1. デモ用ディレクトリで`claude`を起動する
2. `/context`を打ち、出力を上から指す
3. `System prompt`、`CLAUDE.md`、`Auto memory`、`Skill descriptions`の行を順に指す
4. `cat ~/.claude/CLAUDE.md`で自分のCLAUDE.mdが11行しかないことを見せる

### 話すこと

- 「打つ前にこれだけ読んでいる。会話が空でもゼロではない」
- 「CLAUDE.mdは短い。長い手順はskillに移してあるので、一覧に説明文だけが載っている」
- memoryの行があれば「これはAIが自分で書いたメモの索引」と一言添える

### 失敗時

- `/context`が出ない、起動が遅い: 事前のスクリーンショットへ切り替える
- 見せたくない行が混ざる: その行は指さず、スクリーンショットへ戻る

## 実演2: hookが実行を止める場面を見る

挿入位置は24枚目のあと。所要時間は4分。24枚目に同じ場面のスクリーンショットがあるので、再現できなければそれで足りる。

見せたいことは、AIがコマンドを実行しようとしても、hookが機械的に拒否すること。CLAUDE.mdに「読むな」と書くのとの違い。

### 事前に用意する

- デモ用リポジトリに、ダミー値だけの`.env`を置く（`API_KEY=dummy-not-a-real-key`のような値。実値は入れない）
- `~/.claude`の`block-env` hook（PreToolUse）が有効なことを前日に確かめる

### 手順

1. Claude Codeで「.envの中身を表示して」と頼む
2. AIがBashでコマンドを組み立て、`PreToolUse:Bash hook error`で止まる行を指す。折りたたまれていたら`ctrl+o`で詳細表示にする
3. AIが「表示できない」と答え、代わりの手順を人へ返すところまで見せる

### 使わない例

「render.yamlにコメントを足して」は、2026-09-21の撮影時にEditツールのdenyは効いたが、AIがBashの`sed -i`で書き換えてしまい、止まらなかった。
denyやhookは「どの経路を塞ぐか」まで決めないと抜ける実例として口頭で話すにとどめ、実演には使わない。

### 話すこと

- 「AIは実行しようとした。止めたのはAIの判断ではなく、settings.jsonに登録したhook」
- 「CLAUDE.mdに書いた指示は忘れられることがある。必ず止めたいものはここに置く」
- 26枚目の「確実に守らせたいものほど下の段へ」へつなぐ

### 失敗時

- hookが発火しない: 拒否メッセージのスクリーンショットへ切り替え、「前日に確認した画面」と断る
- 発火したがメッセージが長い: 拒否の1行だけ読み上げる

## 撮影の手順（スライド用スクリーンショット）

2026-09-21に7枚目と24枚目を撮った方法。cmux-cuaが使える環境ならそちらでよい。

1. デモ用の使い捨てリポジトリを`build/`の下に作る（`git init`、README、ダミーの`.env`）。秘密の実値は置かない
2. `ttyd -p 7681 -i 127.0.0.1 -W -t fontSize=22 -t 'theme={"background":"#1a1a1a","foreground":"#ffffff"}' zsh`で
   ローカル限定のターミナルをブラウザに出す（`brew install ttyd`）
3. Claude in Chromeで`http://127.0.0.1:7681/`を開き、ウィンドウを1280×800にして`claude`を起動。フォルダ信頼の確認は「Yes」
4. `/context`、「.envの中身を表示して」の順に操作し、`ctrl+o`で詳細表示にしてから撮影（`save_to_disk`）
5. 撮影後は`/exit`、`pkill -f 'ttyd -p 7681'`、タブを閉じる。デモ用リポジトリは消してよい
6. 元画像を`assets/shots/raw/`へ置き、`scripts-blur.py`でパスを塗り、`ffmpeg crop`で要点を切り出す
