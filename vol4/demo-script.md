## 実演1: Museに用事を頼み、許可を求める画面まで見せる

挿入位置は10枚目（Muse）のあと。

見せたいことは、目標を渡すと自分で調べて進め、送信や購入の前で止まって許可を待つこと（8枚目の内容）。

### 準備

- [ ] 勉強会専用のMetaアカウントでMuseに入る。個人や業務のメール、カレンダー、支払いはつながない
- [ ] 送信しても困らない宛先（自分の別アドレス）を用意する

### 手順

1. Museを開き、「来週の金曜に、自分の別アドレスへ勉強会の案内メールを書いて送って」と頼む
2. 下書きを作るところまでは自分で進むことを見せる
3. 送信の前に許可を求める画面が出たら止め、ここが「取り消せない操作の前で止まる」場所だと指す
4. 許可せずに取り消す

### 注意

- 許可を押さない。押した場合も、宛先が自分の別アドレスであることを先に確かめておく
- メール連携に専用アカウントを用意できない場合は、旅行の候補を比べさせる（予約はしない）に差し替える
